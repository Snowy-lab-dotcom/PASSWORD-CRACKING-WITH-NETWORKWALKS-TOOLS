# 🔐 PASSWORD-CRACKING-WITH-NETWORKWALKS-TOOLS







## 📌 Project Overview

This project was completed as part of the **Networkwalks Cybersecurity & Ethical Hacking Week 3 Project Module 2**.

The practical focused on understanding how a password-protected PDF can be analysed by extracting its password hash and using a password-cracking tool to recover the password.

The practical used two Networkwalks online tools:

* **Networkwalks Hash Calculator** – used to extract the password hash from the locked PDF.
* **Networkwalks Password Cracker** – used to process the extracted hash and recover the password.

The recovered password was then used to verify access to the protected PDF.

---

## 🎯 Objectives

The main objectives of this practical were to:

* Understand the basic concept of password cracking.
* Extract a password hash from a protected PDF.
* Use a password-cracking tool to recover the password.
* Verify the recovered password by opening the protected PDF.
* Understand the importance of strong passwords.

# 📚 Lessons Learned

### 1. Password Hashes

I learned that password-protected files can contain information that can be processed to obtain a password hash. The hash can then be used as input for a password-cracking process.

### 2. Password Cracking Workflow

The practical helped me understand the basic workflow:

```text
Protected PDF
      ↓
Hash Calculator
      ↓
PDF Password Hash
      ↓
Password Cracker
      ↓
Recovered Password
      ↓
Test Password
      ↓
PDF Unlocked
```

### 3. Weak Passwords

The practical demonstrated how simple passwords can be vulnerable to password-cracking techniques.

### 4. Password Security

I learned the importance of using strong and difficult-to-guess passwords instead of short or commonly used passwords.

### 5. Practical Cybersecurity Skills

This practical provided hands-on experience with:

* Password hashes
* Password-cracking concepts
* Protected PDF files
* Hash extraction
* Password recovery
* Security verification
* Ethical hacking practices
